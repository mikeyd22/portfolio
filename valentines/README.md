# Valentine's 80s/90s Site ♥

A small two-page site: **landing** (intro) → **love** (messages + visuals).

## Replace placeholder images

1. Create an `images` folder in this project.
2. Add your photos with these names (or any names — then update the HTML):
   - `us-together.jpg` — Your favourite photo together
   - `memory-1.jpg`, `memory-2.jpg`, `memory-3.jpg` — Memory gallery
   - `promise-or-date.jpg` — A special moment or place
   - `valentines-heart-or-couple.jpg` — Favourite pic or a heart
3. In `love.html`, replace each gray placeholder box with an image tag, e.g.:

   ```html
   <img src="images/us-together.jpg" alt="Us together" class="placeholder-img">
   ```

   Use the same `placeholder-img` class so the neon border and styling still apply.

## Run it

Open `index.html` in your browser (double-click or use “Open with Live Server” in VS Code).
